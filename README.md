### About Me

Hi, I'm Sanne! I'm a software developer and systems engineer based in Amsterdam with **10+ years of engineering experience** building high-throughput distributed systems, concurrent networking runtimes, and resilient data infrastructure.

After completing my **M.Sc. in Computer Science (Systems & Network Engineering / Distributed Systems) at the University of Amsterdam (UvA)**, I have spent the last decade building low-latency, mission-critical infrastructure across the European systems ecosystem. My engineering work centers on building deterministic software where concurrency invariants, memory layouts, and wire protocols meet high throughput:
- **Distributed Systems & Consensus:** Raft/Paxos state machines, lock-free synchronization, deterministic event loops, and robust backpressure controls.
- **Async Runtimes & Networking:** High-performance async I/O in Rust (`tokio`), Go, and modern C++.
- **Columnar & Data Infrastructure:** Stream processing, binary serialization, protocol buffers, and zero-copy memory pipelines.

---

### Engineering Principles

- **Invariant Integrity:** Design state transitions so that illegal states are impossible to represent at compile time.
- **Predictable Concurrency:** If a concurrent state machine cannot be verified deterministically under failure injection, simplify the architecture.
- **Defensive Precision:** Strict adherence to zero-regression validation, clean atomic commits, and reproducible test suites.
